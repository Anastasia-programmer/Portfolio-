## Project description

This is my personal portfolio. It is a one page website where a visitor can see who I am, my skills, my projects, my experience and education, and how to contact me.

The page has these sections:

- **Home**: my name, my role and two buttons (projects and contact)
- **About**: a short presentation and my main information
- **Skills**: my skills grouped in cards (frontend, backend, AI & testing, tools, soft skills, languages)
- **Experience & Education**: my work experience and my studies
- **Projects**: my projects with a picture, a description and a link
- **Contact**: my contact information and a contact form

## Technologies used

- **HTML5**: structure of the page with semantic tags (`header`, `nav`, `section`, `footer`, `form`)
- **CSS3**: Flexbox, Grid and media queries for the responsive design
- **JavaScript**: DOM manipulation and events (clicks and form submission)
- **Google Fonts**: Poppins
- **Tools**: Visual Studio Code, Google Chrome DevTools, Git and GitHub

## Implemented features

1. **Responsive design**: the page adapts to desktop, tablet (under 900px) and phone (under 600px) using media queries.
2. **Mobile menu**: on small screens the menu is hidden and the ☰ button shows or hides it (JavaScript).
3. **Contact form**: when the form is sent, JavaScript checks that all the fields are filled and shows a message (red if something is missing, green if everything is good).
4. **Smooth scrolling** when clicking a link in the menu.
5. **Hover effects** on the links, buttons and cards.
